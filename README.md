# learn-tailwind-daily
我想通过每天学习一个Tailwind的小知识来逐渐掌握Tailwind


进行本教程前，需要学一点点React的知识：https://github.com/JuLongZhiLu/learn-react-daily

这并不是一个严谨的项目，可能会有很多错误，因为其中记录的大部分内容只是我和AI的对话。

不过随着我对Tailwind的掌握加深，我可能会回过头来修改之前的内容。

----
这是个很好的思路。

很多人学 Tailwind 失败，不是因为 Tailwind 难，而是一开始就试图：

- 学完所有 Utility Classes
- 学完 Flexbox
- 学完 Grid
- 学完 Responsive Design
- 学完 Dark Mode
- 学完 Animation
- 学完 自定义 Theme
- 学完 Tailwind Config

结果信息量过大，坚持不下来。

而「每天一个 Tailwind 小知识」实际上更符合长期学习规律。
